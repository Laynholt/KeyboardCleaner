# Keyboard Cleaner

Приложение для чистки клавиатуры ноутбука или ПК: включение и выключение мышью,
визуальная подсветка перехваченных клавиш, тёмная и светлая темы. Интерфейс на русском.

Один Win32-процесс, C++20, GDI+ для окна и схемы клавиатуры. Кнопки из соседней
библиотеки win32-custom-widgets, подключённой через add_subdirectory без изменений.
Минималистичное окно с собственной строкой заголовка, адаптацией к DPI и размеру.
Никаких стандартных message box: ошибки отображаются в окне.

WH_KEYBOARD_LL работает в отдельном потоке с собственным циклом сообщений.
Callback только обновляет состояние и возвращает ненулевое значение для блокировки.
UI читает опубликованный снимок; рисование и обработка кнопок не тормозят hook.
Выход: кнопка либо удержание левого Ctrl + правого Shift в течение 1,5 секунды.
После выхода повторные нажатия и отпускания уже перехваченных клавиш подавляются
до их отпускания. Перед включением пользователь должен отпустить все клавиши.
Закрытие, завершение сеанса и сон снимают hook. Второй экземпляр не блокирует клавиатуру.

Это фильтр обычного ввода на текущем интерактивном рабочем столе, не отключение устройства:
Ctrl+Alt+Del, защищённый рабочий стол Windows, питание и аппаратные Fn вне гарантий.
Программы с отдельными путями ввода (например, Raw Input) требуют ручной проверки.
Клавиши не записываются на диск и не передаются по сети.

Проверка: тесты состояния (повторы, drain, сторона модификаторов, длительность,
отмена сочетания, нормализация numpad); интеграционный тест настоящего hook
с SendInput и окном-получателем; сборка Release; снимки обоих вариантов оформления.
